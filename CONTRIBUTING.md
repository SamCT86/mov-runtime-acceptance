# Contributing

This repository exists to make MOV's public contracts, examples, release verification, and developer boundary inspectable.

## Good public contributions

- documentation corrections;
- clearer integration examples;
- reproducible issues against the public 0.1.0 artifact;
- compatibility observations that do not include secrets;
- corrections to public schema/discovery documentation.

## Not handled through this repository

MOV's private implementation core is not mirrored here. Pull requests that assume access to or attempt to reconstruct unpublished kernel, payment, signing, infrastructure, commercial, or operational components are outside this repository's scope.

## Before opening an issue

Please include:

1. MOV version;
2. operating system / Node version when relevant;
3. the exact public command or interface used;
4. expected behavior;
5. observed behavior;
6. a minimal non-sensitive reproduction.

For security-sensitive reports, use `sarmad@machineoutcome.com` instead of a public issue.
